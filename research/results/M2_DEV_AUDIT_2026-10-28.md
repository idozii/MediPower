## Legacy classifier rerun

All three splits train the legacy `TfidfVectorizer(ngram_range=(1,2), sublinear_tf=True)` + balanced LogisticRegression model, with seed 42. For the random split, this matches the original seed, split fraction, stratification and preprocessing.

**Interpretation:** the random holdout contains 17 repeated exact model inputs, an avoidable evaluation contamination. Yet perfect grouped/template-holdout performance remains; duplicate contamination alone does not explain the model score. The dataset remains highly stylized and disease vocabulary may be highly separable. None of these splits tests natural clinical descriptions, cross-institution transfer, comorbidities, novel symptom language, unknown diagnoses, or safety-critical triage. No inference about real-world clinical accuracy can be made.

## Retrieval implementation sanity check (NOT a benchmark claim)

TF-IDF and BM25 baseline exporters were run against the 29-condition toy catalog and 4 hand-written development queries (3 positive, 1 non-clinical negative), using a separate ID-based evaluator.

Both methods produced `Recall@1 = 0.8333`, `Recall@3 = 1.0`, `MRR@3 = 1.0`, and `negative_false_positive_rate = 0.0` on **one** negative example. The small number of hand-selected queries and overlapping catalog wording make these numbers unfit for model comparisons or publication. Dense/hybrid were implemented but **not executed** by this lightweight CI job; no outcomes are claimed for them.

## What has been validated

The GitHub Actions workflow completed 16 unit and regression tests, the legacy data audit, lexical baseline exports and toy evaluation successfully. The existing production `/predict` API uses the disease retrieval pipeline, **not** the 8-class classifier audited here.

## Next research decision

Freeze an externally sourced, permitted dataset with independent symptom-text annotations and non-clinical/emergency negative controls. Preserve source/patient/template disjointness. Only then run official retrieval benchmarks for TF-IDF, BM25, dense, hybrid and the production heuristic pipeline; report confidence intervals, missing/incorrect referrals and failure cases. A qualified clinical review is essential before any patient-facing claim.
