# M6 — Research reproducibility and paper-preparation gate

## Deliverables
- A reproducible Markdown result-draft generator, research/build_research_report.py, reading only actual JSON generated by M4 compare_models.py.
- An academically cautious paper outline in paper/MANUSCRIPT_OUTLINE.md with no invented external metrics.
- Unit tests that explicitly prevent a development run from being described as submission-ready.

## Produce draft results once M4 outputs exist
    python -m research.build_research_report --comparison research/outputs/m4-comparison.json --out research/outputs/paper/results_draft.md

Generated output is in ignored research/outputs and must be reviewed before sharing. It is not evidence of clinical validation or conference acceptance.

## Release blockers (manual, explicit)
- [ ] License/source/version checksums and required attribution.
- [ ] Independent expert-reviewed DDXPlus-to-MediPower pathology mapping with reported coverage.
- [ ] Adequate development sample sizes and precommitted test protocol and alpha selection.
- [ ] All evaluated methods use the same catalog and supported labels.
- [ ] Evidence of patient/source/template separation; paired bootstrap with independently sampled units or clustered bootstrap when applicable.
- [ ] Written authorization for official test access; freeze and hash configuration before unsealing test.
- [ ] Full negative-control and safety failure report with qualified clinical reviewer.
- [ ] Document model revision, package locks, OS/environment and random seeds.
- [ ] Peer-reviewed related-work/novelty assessment before conference submission.

**Project stage:** M1–M6 engineering scaffolding and development-only checks; external research evaluation is BLOCKED until actual permitted source files, manual mapping, relevant expert review and test authorization exist. No automatic code check can grant clinical or research-data permission.

## Potential future venue strategy
First aim for a transparent replication/benchmark report or AI healthcare workshop with reproducibility and meaningful failure analysis. A full paper will depend on actual novelty, experimental strength and independent validation; do not pre-label it NeurIPS/ICML/AAAI quality.
